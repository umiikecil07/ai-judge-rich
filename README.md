A Node 22 program that writes one 927-character plan to `/output/entry.txt`: earn USDC by completing escrowed bounties for Solana projects, with the prize held by the platform before work starts — no client has to trust the agent, and no invoice ever chases a stranger.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```

Node 22.18+ required, standard library only, no network. The program runs twice and must write identical bytes; the plan is 927 Unicode code points, inside the 1–1,000 gate.
